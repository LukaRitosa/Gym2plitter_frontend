# Gym2plitter

Frontend aplikacija za Gym2plitter projekt, izrađena s Vite 3 i TailwindCSS.


## Lokalno postavljanje

```bash
git clone https://github.com/LukaRitosa/Gym2plitter_frontend.git
```

## Napomena 1

Prije sljedećih koraka potrebno je promjeniti direktorij.

```sh
cd app
```

## Project Setup

```sh
npm install
```

## Napomena 2

Za rad aplikacije prvo trebate napraviti backend i mongoDB bazu na:

```sh
https://github.com/LukaRitosa/Gym2plitter_backend/tree/main
```

Prije nastavka potrebno je napraviti env varijable sa vlastitim postavkama.

```sh
VITE_BASE_URL=
VITE_ADMIN_MAIL=
VITE_ADMIN_LOZINKA=
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
